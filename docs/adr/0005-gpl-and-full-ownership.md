# GPL-3.0-or-later, and the owner holds the copyright to all code

nibble is open source but its owner may sell closed modules later. GPL stops anyone shipping a closed paid fork; dual-licensing closed modules stays possible only while the owner holds the copyright to every line. Hence: contributors sign a CLA, no code is copied from other projects (including GPL-compatible ones like Vorssaint), and dependencies stay permissively licensed, enforced by cargo-deny.

## Considered Options

- FSL / PolyForm Noncommercial: stop commercial forks outright, but are not open source.
- MIT / Apache-2.0: let anyone sell a closed fork.
